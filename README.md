# 📊 Power BI - Dashboard de Ventas 2010-2024 BWM

Este es mi primer proyecto, muestra un análisis interactivo de las ventas anuales utilizando **Microsoft Power BI**.

El objetivo es visualizar el rendimiento de ventas, identificar patrones y detectar oportunidades de mejora.

## 📁 Archivos incluidos

- `Ventas BMW.pbix`: archivo principal del dashboard.
- `BMW ventas.csv`: datos ficticios de ejemplo descargados de internet
- `capturas/`: imágenes de las páginas del reporte.
- `capturas/`: imágenes de algunas de las medidas DAX utilizadas.
