# 📊 Power BI - Dashboard de Ventas BMW (2010–2024)

Este es mi primer proyecto desarrollado con **Microsoft Power BI**, en el cual realizo un **análisis interactivo de las ventas anuales de BMW** durante el periodo 2010–2024.  

El objetivo principal es **visualizar el rendimiento de ventas**, identificar **patrones de comportamiento**, y detectar **oportunidades de mejora** mediante el uso de DAX y visualizaciones dinámicas.

---

## 📁 Archivos incluidos

- **`Ventas BMW.pbix`** → archivo principal del dashboard en Power BI  
- **`BMW ventas.csv`** → conjunto de datos ficticios de ejemplo (descargado de internet)  
- **`capturas/`** → imágenes de las páginas del reporte y ejemplos de medidas DAX utilizadas

## 🧠 Indicadores principales

- Ventas y facturación total  
- Ventas por región y por año  
- Características de los vehículos vendidos  
- Comparación entre modelos con **altas vs. bajas ventas**  
- Análisis de correlaciones y matrices de datos  
- Productos más vendidos  

---

## 🛠️ Tecnologías utilizadas

- **Microsoft Power BI** – creación del dashboard  
- **DAX** – cálculos e indicadores personalizados  
- **Excel** – preprocesamiento y limpieza de datos
